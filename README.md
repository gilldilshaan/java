## 🚀 How to Run

<details open>
<summary><b>🪟 Windows (Command Prompt / PowerShell)</b></summary>

```bash
:: Compile a program
javac basics\First.java

:: Run it
java First
```

</details>

<details>
<summary><b>🍎 macOS / 🐧 Linux (Terminal)</b></summary>

```bash
# Compile a program
javac basics/First.java

# Run it
java First
```

</details>

<details>
<summary><b>📦 Compile everything at once</b></summary>

```bash
for f in $(find . -name "*.java"); do javac "$f"; done
```

> **Note:** compiled `.class` files are automatically ignored via `.gitignore`.

</details>
